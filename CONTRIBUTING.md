# Guia de Contribuição

Obrigado por querer contribuir com este repositório! Siga as orientações abaixo:

## Como Contribuir
1. Crie uma branch para a sua alteração:
   git checkout -b feature/nome-do-exercicio

2. Adicione e teste sua solução na estrutura de pastas correta.

3. Salve suas alterações com commit semântico:
   git commit -m "feat: adiciona resolucao do exercicio X"

4. Envie a branch para o repositório remoto:
   git push origin feature/nome-do-exercicio

5. Abra um Pull Request no GitHub descrevendo o que foi feito.

## Padrão de Branches
- feature/ : Para novas resoluções ou novos exercícios
- fix/     : Para correções em códigos existentes
- docs/    : Para documentação e explicações
